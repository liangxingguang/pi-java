> **pi 锚点：`3390bd936`（2026-09-20）** —— 上一版对 `71dca871b`（2026-09-11）测；本轮重测跨越 **111 个提交**。
> 判定三档：**对齐** = pi 有 ∧ pi-java 有 ∧ 行为相同（读代码确认语义）；
> **缺失** = pi 有 ∧ pi-java 无（或只有严格更小的子集，且差异有行为后果）；
> **存疑** = pi-java 有但形状/行为未核，**或**差异是刻意设计/跨模块/待裁决；
> **作废** = pi 已删除该构造（按裁决 R1）。
> 所有证据为 `file:line`，两侧均已打开源码确认。
>
> **权重** = 用户可观察影响 × 频率（用户裁决口径，不含排期优先级）：
> **3** = 每轮对话都走/默认路径；**2** = 每次会话走/常用；**1** = 低频/边缘/纯内部；**0** = 非目标，**排除出分母**。
> 完成系数：对齐 1.0 ／ 存疑 0.5 ／ 缺失 0 ／ 作废 0。
